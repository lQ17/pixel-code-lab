# 页面重构实施方案：入口页与精简工作台

日期：2026-09-22。基线提交：`afea7f4`（feat: 增加二维积木编程最小原型）。
状态：已于 2026-09-22 实施完成。本文保留实施方案，当前行为与验证记录以《交接文档.md》《开发记录.md》为准。

## 1. 任务目标与范围

用户要求：界面只突出代码区、参考图和运行展示区，其余信息折叠为菜单等形式；挑战与自由创作放到独立入口页面，选择后进入工作台。

本轮统一覆盖二维挑战、二维自由创作（Python/积木）、三维挑战、三维自由创作。沿用深色科幻终端风格、左编辑右上下对照，不改执行、判定、坐标和作品协议。这里的“实时运行展示”指展示当前执行状态及成功结果，**不增加输入后自动执行、逐帧运行或实时 Python 解释**。

完成后，默认工作台只有一行紧凑菜单栏和三个主区域；不再常驻关卡侧栏、玩法切换栏、文件栏、作品工具栏、大运行面板、调色板或帮助说明。菜单只是功能的新入口，原有能力全部保留。

不纳入：账号、云端、课程、社区、新关卡、移动端专用编辑器、积木扩展到挑战/三维、编辑器分栏拖动及全屏等附加功能。

## 2. 页面与导航

### 2.1 入口页

实现一个可复用的入口页，不分别复制四套页面。页内提供「挑战 / 自由创作」以及「2D / 3D」选择，工作台内不再显示这些切换器。

- 挑战：显示对应维度的全部关卡卡片、历史通关标记及总进度。二维三关、三维七关全部开放。点击某关进入对应工作台，恢复该关草稿，不运行、不载入答案、不自动跳关。
- 自由创作：显示「进入创作」主入口，恢复该维度当前草稿及二维上次编辑方式；可显示最近作品列表的简要入口，但不要另做一套作品管理。第一版仅主入口即可，作品库在工作台的「作品」菜单打开。
- 提供「继续上次工作」快捷入口，目的地从已有 mode / activity / levelId 等字段推导。旧存档缺省规则沿用当前实现，不能因为进入入口页而重写这些字段。
- 参考选择留在工作台的「参考」菜单；进入创作不强迫学生先选模板，不自动以示例覆盖已有草稿。
- 工作台左上角「返回入口」回到当前维度和玩法对应的入口页。浏览器前进、后退也必须可用。

### 2.2 推荐路由约定

复用现有 Vite 静态部署方式，优先使用 Hash 路由，无须新增服务端重写或大型路由依赖。页面导航属于同一 SPA，不用 location.href 跳转整个站点。

| URL | 页面 |
| --- | --- |
| `#/start/challenge/2d` | 二维挑战入口 |
| `#/start/challenge/3d` | 三维挑战入口 |
| `#/start/create/2d` | 二维创作入口 |
| `#/start/create/3d` | 三维创作入口 |
| `#/work/2d/challenge/<levelId>` | 对应二维关卡 |
| `#/work/3d/challenge/<voxelLevelId>` | 对应三维关卡 |
| `#/work/2d/create` | 当前二维创作草稿 |
| `#/work/3d/create` | 当前三维创作草稿 |

根地址首次显示入口页，默认按已有存档选择玩法/维度；入口页面也提供明确的继续按钮。有效工作台链接刷新后恢复同一上下文，但结果仍遵循当前“刷新后手动运行”的规则。非法维度、玩法、关卡或未知地址回退入口页，不能凭非法 URL 创建关卡、覆盖草稿或触发执行。

路由不包含 Python 内容、积木 JSON、本地作品内容。首轮不增加单件作品深链接。切换编辑方式或参考图不创建浏览历史记录。

## 3. 工作台布局

```text
┌ 返回入口 │ 当前任务/作品短名称 │ 作品▾ 编辑▾ 参考▾ 视图▾ 运行▾ 帮助▾ ┐
├────────────────────────────┬───────────────────────────────┤
│                            │ 目标图 / 参考图                │
│                            │                               │
│  Python 或积木编辑区        ├───────────────────────────────┤
│                            │ 运行结果                      │
│                            │                               │
└────────────────────────────┴───────────────────────────────┘
```

- 移除左侧关卡栏，释放宽度给编辑区。编辑区约占 48%，右侧约 52%；右侧上下各半，不改变图形比例。具体比例可按真实截图微调。
- 顶栏建议 44～48 px；面板标题控制在 28～32 px。删除 CODE TERMINAL、TARGET、YOUR CREATION 等重复装饰说明，不再额外占一行展示文件名、语言和网格尺寸。
- 标题只保留必要身份：「代码 · Python/积木」「目标图/参考图 · 名称」「运行结果」。长任务/作品名截断并提供完整 title，不能把菜单挤出屏幕。
- 运行、保存、坐标系等操作全部通过菜单；**不恢复常驻的大运行按钮或按钮工具条**。运行中的菜单触发器可显示「运行中…▾」，确保停止操作在一次展开后即可点击。
- 匹配率、已生成、历史结果、剖切中等属于当前图像的必要简短状态，可放在结果/参考标题的右侧；详细耗时、体素数、剖切数值和历史说明收进菜单或详情浮层。
- 未运行画布只显示短占位，不显示大段教程。调色板、日志、生成的 Python 默认关闭。
- 普通成功提示短暂出现后消失；错误和存档失败有明确例外，见第 5 节，不能把错误永久藏在菜单里。

### 尺寸要求

1440×900 和 1180×768 是主要验收尺寸：默认无页面级横向滚动，无底部工具栏挤压，三个区域同时可见；编辑内容可正常滚动，Canvas 填充可用区域并保持等比。

菜单较窄时可将低频入口并入「更多」，不得形成第二行常驻工具条。低于桌面目标宽度允许垂直堆叠及页面滚动，不能遮住运行、停止和返回入口；首轮不追求完整手机编辑体验。

## 4. 功能收纳清单

| 现有内容 | 新位置 | 行为及可见条件 |
| --- | --- | --- |
| 2D/3D、挑战/自由创作 | 独立入口页 | 工作台通过返回入口切换 |
| 三关/七关列表、总通关进度 | 挑战入口页 | 全部开放，保留历史通关 |
| 保存、另存、作品库、新建、命名 | 作品菜单/现有作品库弹窗 | 仅自由创作；命名和列表管理继续复用原弹窗 |
| JSON 导入/导出、PNG | 作品菜单/作品库弹窗 | 当前作品和列表作品的导出语义不变；PNG 仅匹配的成功结果可用 |
| Python/积木切换 | 编辑菜单内单选项 | 仅二维自由创作；切换不转换、不覆盖另一草稿 |
| 复制为 Python 作品 | 编辑菜单 | 仅有效积木；创建独立副本，不自动切换 |
| 恢复初始代码/积木 | 编辑菜单中的分隔组 | 沿用覆盖确认；不可因收纳而变成一键无确认清空 |
| 颜色 0～8 | 编辑菜单 → 颜色表浮层 | 编号、色块、中文名齐全；0 为空白而非白色 |
| 只读 Python 对照 | 编辑菜单 → 查看生成代码 | 仅积木；打开侧抽屉/弹层，默认关闭，不挤占编辑器高度 |
| 参考图/模型选择 | 参考菜单 | 仅自由创作可选；只换参考，不修改代码或作品 |
| 载入示例 | 参考菜单中独立分隔项 | 二维创作和三维两玩法有；二维挑战没有；替换前沿用确认 |
| 网格尺寸/当前参考说明 | 参考菜单详情 | 二维挑战不得暴露公式、解法或错误格定位 |
| 坐标辅助/坐标系模式、重置视角 | 视图菜单 | 复用现有共享状态，两图同步 |
| 三维剖切开关、恢复完整模型 | 视图菜单 | 见下方剖切规则；不改变模型或判定 |
| Blockly 适应积木、操作提示 | 视图菜单/帮助 | 仅积木；画布内原生缩放控件可隐藏，通过滚轮与菜单操作 |
| 运行、停止、重试 Python 加载 | 运行菜单 | 按 ready/running/failed 等既有状态禁用；停止不能被藏进多层子菜单 |
| Python 加载状态、耗时、体素数 | 运行菜单详情 | 正常状态无需单独常驻一行，加载失败主动显示短提示 |
| 程序输出及错误详情 | 运行菜单 → 输出面板 | 默认关闭；本次运行报错自动打开；不沿用上次输出冒充新结果 |
| 保存状态、重试保存 | 作品菜单详情与异常提示 | 成功状态收纳；失败不能只放在关闭的菜单中 |
| 使用说明、鼠标/键盘提示 | 帮助菜单 | 沿用已有说明内容，按当前模式展示，不扩展为新课程系统 |

挑战模式隐藏作品菜单。必要的保存失败提示仍可直接提供「重试保存」操作，不能依赖不可见的作品菜单。菜单项隐藏/禁用基于真实能力与运行状态，禁用时提供简短原因；不能点完才发现操作不存在。

积木原生工具箱属于编辑器：保留窄分类入口，展开后显示积木，拖出后自动收起 flyout。不能将它与全局调色板一起隐藏到无法拖拽，也不能牺牲鼠标连线、删除、撤销和字段编辑。

三维剖切：默认收起操作手柄，通过「视图 → 剖切工具」显式打开；工具打开时画布上的投影手柄属于编辑操作反馈。关闭工具仅隐藏手柄，不重置 cuts；已有剖切时标题保留小型「剖切中」标识，菜单可恢复完整模型。坐标辅助与模型投影规则不变。双图始终共用 cuts/view，PNG 导出仍使用完整模型。

## 5. 交互与异常规则

- 菜单默认全部关闭，同一时间只打开一个。点击外部、Esc、完成普通操作后关闭，关闭后焦点回到触发按钮。弹窗按原方式处理焦点。
- 触发器需有可访问名称、aria-expanded/aria-controls；完整实现方向键、Enter、Esc 后再使用 menu/menuitem 角色，否则采用语义正确的按钮+弹出面板。不能只靠 hover，也不能仅使用无标签图标。
- 可增加 Ctrl/Cmd+Enter 运行（菜单中显示提示），但须验证 Monaco/Blockly 不重复触发、中文输入组合态不触发、弹窗输入时不触发。不是交付必需项；菜单运行路径必须完整。
- 运行错误主动展开紧凑输出面板，保留真实行号、Monaco 定位与积木高亮；用户可关闭。下一次运行清理旧错误，继续沿用当前执行规则。
- 存储读取失败、写入失败、损坏存档、超限积木等必须在当前页显示简短且持续的警告入口，入口页也不能丢掉未解决的存储警告；原有显式恢复和备份能力保留。
- 历史图像保留「历史结果」标识，详细说明按需展开。编辑、失败或停止不能显示成最新成功图，也不能用旧结果生成新代码的 PNG/预览。
- 首次说明不再强制遮住工作台；在入口页给非阻塞的帮助入口。兼容 introSeen 字段，不因页面改版重新弹出旧教程。

## 6. 路由、草稿与执行状态的保护

这是本次除布局以外最重要的实现部分。

1. 将工作会话状态保留在页面切换不会卸载的上层：useProgress、Runner、generation、works/stale、当前编辑上下文和共享视图。可提取专用 hook/provider，但不重新实现执行器和持久化层。
2. 定义统一 navigateTo/activateContext 路径，按钮、入口卡片、前进后退都走同一套上下文检查；不能只在 onClick 中取消运行。导航被拒绝时恢复此前 URL，避免地址显示新关、内容仍是旧关。
3. 离开工作台或切换上下文时先递增 generation，再 stop 当前任务，阻止异步完成回写目标页面。纯粹展开菜单不停止运行、不重建编辑器/Worker。
4. 仅离开页面不会覆盖草稿，不需要新增泛化的“是否离开”确认；保留当前内存草稿并即时尝试现有存档写入，防抖期间最后一次输入不得丢失。存储失败仍保留会话状态和警告，禁止通过卸载状态提供器丢掉内存内容。
5. 打开/新建作品、载入示例、恢复模板等会替换内容的操作，继续调用已有业务方法，保留确认、草稿备份及先落盘后切换。跨 Python/积木打开作品仍保护两侧草稿。
6. 存在超限/无法序列化的积木可见修改时，返回入口、浏览器后退和切上下文也要使用现有阻止切换规则，要求先撤销或修正；不能绕过 blocksError 后保存旧结构。
7. 入口页和菜单只传稳定 ID，不按数组序号迁移数据。URL 中挑战 ID 的优先级仅用于合法导航上下文，不覆盖该关已保存代码。
8. 返回工作台可保留本会话成功结果，刷新后按现有规则等待手动运行；不要新增运行结果持久化。本轮无需更改 schemaVersion、作品文件版本和 storage key。
9. 保持浏览器 origin 和现有开发地址，不改端口来规避存档问题；Hash 不会改变 localStorage 来源。

实施顺序：

1. **导航与入口页**：实现路由、卡片及返回入口；保留现有工作台作为过渡，先测前进后退、刷新、取消运行和草稿保存。
2. **精简工作台**：去掉侧栏及常驻工具区，加入一行菜单栏；按第 4 节逐项搬迁功能，不并行重写业务逻辑。
3. **按需辅助界面**：颜色表、Python 对照、输出面板、三维剖切工具与错误提示；完成焦点和键盘交互。
4. **真实渲染与回归**：检查所有五种编辑上下文和两个目标尺寸，修复菜单遮挡、画布尺寸、积木连接以及状态问题，再更新文档。

每一步都保持项目可运行；不要求中间 Git 提交。用户当前授权的是已完成原型的单次提交，后续实现不要自动提交或推送。

## 8. 验收与测试清单

### 布局与操作

- 在 1440×900、1180×768 截图核对五种上下文：二维挑战、二维 Python 创作、二维积木创作、三维挑战、三维创作。
- 默认只显示一行菜单、三个主区域及必要标题/短状态，没有旧关卡栏、调色板、运行面板和叠加的多行工具栏。
- 每个原有操作都可从表中指定入口到达；菜单没有屏外溢出，点外部/Esc/键盘切换及焦点恢复正常。
- 逐项检查颜色表、代码对照和输出面板的展开/关闭；Blockly 原生下拉、数字输入、拖拽连接、删除、撤销、适应工作区不受全局菜单样式影响。
- 画布缩放、平移、旋转、悬停坐标及两图联动与现状一致。打开/关闭菜单或辅助面板后，Monaco/Blockly/Canvas 正确重算容器尺寸，不出现空白或拉伸。

### 导航和数据保护

- 入口全部关卡开放；选择卡片/继续上次/返回入口/前进后退/直接访问工作台/刷新/非法地址都得到确定结果。
- 在自动保存防抖窗口内输入最后一行并离开再返回，内容完整。Python、积木、各关和二维/三维草稿互不覆盖。
- 死循环运行时返回入口、切玩法或后退，任务取消且可再次运行，过期结果不能污染新页面。
