# 开发记录

## 2026-09-17 · Python 执行与判定阶段

完成 PythonRunner、Pyodide Worker、独立 Python 包装执行器、Canvas、匹配引擎与 UI 状态。运行文件由 npm 安装后在启动/构建时复制，不纳入 Git；package-lock.json 固定安装依赖。

Python 用户代码使用 student.py 文件名编译；异常提取用户栈行号。非法返回值没有 Python 异常栈，提示函数定义行并明确说明；超时、缺少函数不伪造行号。只接受 type(value) is int 且 0≤value≤8。

运行时超时2秒与初始化超时60秒独立。取消、超时终止 Worker 并恢复；切关递增界面任务编号，避免旧 Promise 更新新关卡。React 卸载释放 Worker。默认无输入流、无自动额外包安装。

匹配率只统计双方至少一方不为空的格子；完全一致才通关，显示值不会四舍五入误报100%。通关状态仅在当前会话保留。

验收：Playwright 使用 Windows Microsoft Edge 和真实 Pyodide，验证三个解法、语法/运行行号、非法返回值、无旧函数残留、输出截断、空白/多画/错色判定、停止/超时/切关恢复和加载失败重试。构建、静态检查及最终测试结果见对应 Git 提交时验证记录。

待后续：Monaco、联动缩放平移、localStorage、首次说明。规划书中的完整 V0.1 验收尚未全部完成。

最终验证：生产构建通过；oxlint 无警告；Windows Edge 上 4 组 Playwright 测试全部通过（34.6 秒）；已查看正方形通关页面截图。

## 2026-09-17 · 编辑器、联动画布与持久化阶段

接入本地 Monaco ESM 与 editor Worker，只注册 Python 语法；编辑器独立懒加载，不依赖 CDN。配置行号、四空格、查找、括号匹配与执行错误标记。错误标记只应用于对应版本代码，编辑后清除旧标记。

两个 Canvas 使用同一 ViewState。滚轮以指针为缩放中心，拖动任意图同步平移；共享放大/缩小/重置按钮。命中检测逆向使用相同变换，范围外返回空，不钳制到边缘。切关重置视图。

localStorage 存储 schemaVersion=1、每关代码、通关、上次关卡、首次说明。300ms 防抖；切关、通关、关闭说明、恢复模板立即落盘；页面隐藏/离开时刷新待保存数据。代码状态与待保存引用同步更新，避免切关时使用旧代码。

解析存档校验结构和关卡ID；损坏/不兼容时保留原文并暂停覆盖，用户明确确认后才恢复写入。读取失败或配额不足提示用户，不阻断执行。不持久化图形结果，刷新后重新运行。

首次使用原生模态说明，Escape或按钮均可关闭，使用说明入口可再次打开。恢复模板独立于重置视图并要求确认，不撤销历史通关。

本阶段最终验证：生产构建成功；oxlint 无警告；Microsoft Edge 上 9 组 Playwright 测试全部通过（43.2 秒）；已检查 Monaco 与上下联动画布页面截图。Monaco 独立懒加载资源约 692 KB gzip，构建提示大分块但不影响功能。
