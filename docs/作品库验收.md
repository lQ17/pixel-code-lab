# 三维本地作品库 · 手动验收

本轮仅扩展三维自由创作。人工操作手感和目视布局由用户验收；自动化结果见交接文档。

## 入口与已有数据

沿用此前的浏览器和地址 http://localhost:5173/，不要清空存档。若服务未运行，在项目目录执行 `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`。

进入「3D 体素 → 自由创作」，确认原来的代码仍在，代码工作台出现「保存作品」「作品库」。检查二维及三维挑战的原代码与通关记录仍保留。

## 1. 保存与再次打开

1. 使用当前草稿，或按需载入一个示例并运行。
2. 点击「作品库」，填写「当前作品名称」为「我的房屋」，点击「保存作品」。列表出现名称及更新时间。
3. 关闭作品库，修改代码，刷新页面。应恢复刚才的修改，并显示「待保存到作品库」；画面等待重新运行。
4. 点击工作台的「保存作品」，再打开作品库。同一条作品被更新，数量不增加。

## 2. 另存副本

1. 修改代码，进入作品库，把名称改成「房屋第二版」，点击「另存为副本」。
2. 列表应同时有「我的房屋」和「房屋第二版」，当前关联为副本。
3. 分别打开两者，关闭弹窗后查看代码并运行。原作品应保留旧代码，副本显示修改后的代码。
4. 当前作品名称不变时再另存，名称自动增加编号，不覆盖原条目。

## 3. 保护未保存修改

1. 在编辑器中添加注释 `# 尚未保存的修改`，进入作品库，尝试打开另一作品。
2. 出现确认框时取消。当前代码、作品选择和已有列表均不变。
3. 再次打开并确认。列表新增名称带「（草稿）」的条目，旧修改保留在其中，然后打开选中的作品。
4. 打开该草稿条目，确认注释仍在。
5. 「新建草稿」也遵循相同保护规则；新草稿是返回 0 的模板，旧作品不会删除。

## 4. 导入导出

1. 在作品库点击「导出当前作品」，浏览器应下载 JSON 文件。它包含编辑器的当前版本，包括尚未保存到作品库的修改。
2. 点击「导入作品文件」，选择刚下载的文件。列表新增作品，当前代码不被替换，画面不会自动运行。
3. 再导入同一文件，应再新增一个带编号的作品，不能覆盖已有条目。
4. 打开导入作品，关闭弹窗再运行，代码和图形应与导出前一致。
5. 可选：选择其他普通 JSON 文件，应该提示格式错误，原代码与作品列表不变。

列表中每条作品的「导出」导出的是该条已保存版本，与上方「导出当前作品」区分。

## 5. 运行隔离和布局

1. 在当前作品中运行 `while True:` 下一行缩进写 `pass`，马上打开作品库切换作品；也可以等待已有超时恢复。
2. 成功打开后下图为空，不显示上一作品的错误或运行结果。关闭弹窗，再运行新代码，应正常生成。
3. 切到挑战再回自由创作，当前草稿、作品关联和作品库应保留；自由创作不会增加挑战通关数。
4. 检查常用窗口以及约 1180×768 窗口：弹窗可滚动、名称和时间可读，保存、导入和关闭按钮可操作；按 Esc 可关闭弹窗。

## 当前边界

- 作品在当前浏览器本地保存，跨设备使用导入导出。
- 保存作品不要求代码已运行成功；打开后需手动运行，当前版本不保存缩略图或渲染结果。
- 名称最多 80 个字符，代码最多 200000 个字符，JSON 文件最多 1 MB。
- 当前不提供作品删除；新建、另存和导入均保留已有作品。
- 若浏览器存储失败，会提示且不会执行作品切换。可先导出当前内容备份；恢复存储后重新执行保存或打开。
