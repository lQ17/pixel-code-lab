# 三维七关扩充 · 手动验收

本轮新增空心立方体、圆柱、金字塔、简单房屋，并将三维目标与参考选择改为稳定 ID。自动化验证结果见交接文档；以下目视和手动交互验收由用户完成，尚未标记通过。

## 打开项目

沿用此前保存代码的浏览器与地址。最近使用地址为 http://localhost:5173/；如服务未运行，在项目目录执行 `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`。不要为了验收清空浏览器存档；不同域名或端口不会共享存档。

已有自写代码的关卡先检查代码是否完整；载入示例会替换当前代码，出现确认框时按需要取消。四个新关卡首次进入应为空模板，适合先验收。

## 1. 列表与旧数据

1. 进入「3D 体素」→「挑战」。应有七关：立方体、空心立方体、圆柱、球体、彩色阶梯、金字塔、简单房屋。
2. 所有关卡都可直接进入。顶部总数为 7；原有通关数和旧三关代码应保留。
3. 分别查看原有球体和彩色阶梯，确认没有因新关卡插入而串代码。新关卡初始代码只返回 0，不自动载入答案。
4. 在常用窗口及约 1180×768 窗口检查列表、按钮、编辑器与双画布；列表较高时可以在左栏滚动到最后一关。

## 2. 四个新目标

逐一进入新关卡，点击「载入示例」→「运行代码」，每关都应显示 100.0% 与已通关，且不自动跳关。

| 关卡 | 应看到的形状 | 体素数 |
| --- | --- | --- |
| 空心立方体 | 紫色闭合外壳，剖切后能看到内部空腔 | 386 |
| 圆柱 | 绿色竖直实心圆柱，上下圆面相同 | 441 |
| 金字塔 | 黄色方形底座，向上逐层缩小，顶端一个体素 | 455 |
| 简单房屋 | 黄色实心主体、红色坡屋顶，正面蓝色门窗 | 470 |

房屋的门窗为表面蓝色体素，墙体内部实心；空心立方体的内腔才是空白。房屋正面在 Z 正方向，可旋转查看。

## 3. 剖切与坐标

1. 在空心立方体运行成功后，将 X 剖切手柄拖到 0 左右；上下图应同步剖切，内部为空，截面外壳清晰。
2. 拖动空白处旋转、滚轮缩放，确认双图同步；在截面上悬停，应显示正确颜色和坐标，白色高亮贴合体素。
3. 剖切过程中匹配率仍为 100.0%；点击「恢复完整模型」恢复全部外壳。
4. 检查圆柱、金字塔及房屋的内部为实心，恢复完整模型后无缺块。

## 4. 分关代码与历史记录

1. 在空心立方体代码末尾添加注释 `# 我的空心立方体`，切到圆柱，再切回来；注释应保留，圆柱代码不受影响。
2. 点击「载入示例」，在覆盖确认中选择取消；注释应仍保留。
3. 选择「恢复初始代码」并确认，再运行：匹配率应为 0.0%，历史「已通关」仍保留，其他关不变。
4. 刷新页面：所选关卡、代码和历史通关保留；作品和当前匹配率清空，重新运行后生成。

## 5. 自由创作隔离

1. 切到「自由创作」，应有同样七个参考目标。
2. 在无需保留当前创作代码时载入简单房屋示例并运行；下图生成房屋，不出现成绩或通关进度。
3. 仅点击圆柱参考：上图变为圆柱，下图和房屋代码仍保留。
4. 刷新：仍选中圆柱参考，房屋代码仍保留，下图等待运行。
5. 回到挑战：之前所选关卡、代码及历史通关保持独立。

如有问题，请记录所在玩法、关卡、操作步骤和实际现象，尤其是旧代码是否串关、剖切是否错位、窄窗口是否挡住按钮。
