## 1. 定位与范围
面向已学过 Python 函数及 if 的学生，独立观察目标图、归纳规则、编写代码复现图案。Windows 电脑现代 Edge/Chrome 浏览器，默认网络稳定，由学生保证网络可用。

初版仅 Python + 2D + 三个挑战关卡，全部开放。不做自由创作、3D、Blockly、C++、账号、云存储、社区、AI、动画或关卡编辑器。不提供解题提示、参考答案、叠图或错误格定位。任何合法写法均可通关，包括逐点硬编码。

## 2. 坐标与颜色
整数坐标代表格子中心；x 向右、y 向上，原点居中。每关独立配置 radius，范围 [-radius, radius]，包含端点。默认 radius=10，即 21×21；学生不可修改挑战尺寸。首版为正方形，未来可扩展各轴独立对称范围。

固定颜色：0 空，1 红，2 橙，3 黄，4 绿，5 蓝，6 紫，7 白，8 黑。空白与白色编号不同，正式渲染须能区分。颜色表常驻。

## 3. 首批关卡
| ID | 名称 | x、y 范围 | 内部目标规则 |
| --- | --- | --- | --- |
| square | 实心正方形 | -5～5 | abs(x)≤2 且 abs(y)≤2：红色1，其余空白 |
| checkerboard | 双色棋盘 | -4～4 | 铺满9×9，x+y偶数为红色1，否则蓝色5；原点红色 |
| circle | 实心圆 | -10～10 | x²+y²≤64：蓝色5，其余空白 |

规则仅用于开发生成目标，不在学生界面展示公式。目标数据本地保存，不以隐藏源码作为防作弊措施。

## 4. 页面与流程
左侧约40%为代码、运行/停止、错误信息及颜色表。右侧约60%，上方目标、下方作品。两图联动缩放和平移，共用重置视图；显示网格和坐标轴。目标图悬停显示坐标与颜色编号。

首次展示执行说明：系统遍历每个整数坐标，调用 pixel(x,y)，返回整数决定颜色，0为空，无需学生自行写循环。说明可关闭、可再次打开，不含解法。

每关首次使用同一模板：
```python
def pixel(x, y):
    return 0
```
切关保留各关代码；仅无存档时加载模板。恢复代码与重置视图是两个不同操作，恢复代码需防误触。

运行后立即更新作品与匹配率，完全一致记录通关，不自动跳转。关卡全部开放，显示各关通关状态。之后失败不撤销历史通关。

## 5. 判定规范
逐格严格比较颜色编号。U为目标或结果至少一方不为空的坐标集合。匹配率=U中颜色相同格子数/|U|。双方空白不计；多画、漏画、错色均错误。U为空定义100%。当前三关提交全空均为0%。

通关依据精确比较，不依据四舍五入的显示数字。匹配率保留一位小数时，未完全匹配不得显示100%。不显示具体不匹配位置。

## 6. 技术方案
React + TypeScript + Vite；Monaco；Pyodide + Web Worker；Canvas。语言执行与显示分离。Python内部遍历坐标，一次性返回像素数组，避免每格跨语言调用。

运行请求包含代码、范围、任务编号、执行限制。结果包含像素、耗时和限长日志，或错误类型、消息及可用的用户代码行号。Runner提供初始化、执行、停止、销毁。暂不实现复杂多语言框架，Pixel对象数组足够。

目录按需建立：components、engine（关卡/颜色/坐标/判定）、renderers、runners、hooks、docs。

## 7. 执行与错误
区分加载、就绪、运行、恢复、失败。初始执行超时2秒，按实际电脑调整；不计入下载/初始化，覆盖用户顶层代码与遍历。每次只运行一个任务。停止或超时终止Worker并重建，就绪后可再次运行。任务编号丢弃旧结果；切关取消当前执行。

每次使用新的用户命名空间，防止旧函数残留。限制日志长度。Worker用于隔离执行，不等于完整安全沙箱，不能承诺任意内存滥用均无影响。

处理语法错误、缺少函数、参数错误、运行异常、非法返回值。颜色严格为0～8整数，排除bool、浮点数、None。显示错误原因和真实用户代码行号，隐藏内部包装栈；超时等无法定位的错误不伪造行号。

实现默认：失败时保留上次成功作品与匹配率，并标记历史结果；没有历史则显示空状态。失败不产生新成绩，不披露目标答案。

## 8. 本地存储
localStorage带schemaVersion，保存每关代码、通关记录、上次关卡、首次说明状态和必要设置。编辑防抖保存、切关确保最新代码保存。刷新恢复进度，作品重新运行生成。处理存储不可用与损坏数据。无账号、无跨设备同步，浏览器清理数据会移除记录。

## 9. 开发顺序
1. 项目骨架、规划、关卡配置与基础布局（本次范围）。
2. Pyodide Worker最小验证，运行、停止、超时恢复、错误行号。
3. Monaco、Canvas、图案判定与通关闭环。
4. 联动视图、单格查询、首次说明、本地存储。
5. Windows浏览器实测及核心判定测试。

## 10. MVP验收
- 三关尺寸和目标正确、原点居中、y向上、负坐标棋盘正确、圆边界包含。
- 统一模板、关卡全开放；切关与刷新正确保留代码和进度。
- 上下两图联动、目标可查单格、颜色表常驻。
- 运行即判定；完全匹配才通关；多画、漏画、错色均不通过。
- 不提供提示、参考答案或错误格位置。
- 报错显示可用的用户行号，死循环能停止或超时，恢复后可再运行。
- 旧任务不覆盖新结果，运行失败无伪造结果。
