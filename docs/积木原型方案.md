# 积木编程最小原型方案

日期：2026-09-21；实现更新：2026-09-22。状态：已实现二维自由创作最小原型，并扩展到二维挑战及三维挑战/自由创作；下文保留首轮设计，当前行为与验证结果以交接文档和开发记录为准。

## 目标与范围

先在「2D 像素 → 自由创作」验证：拖拽积木 → 生成可读 Python → 运行 → 查看像素 → 保存并重新打开。首轮仅二维自由创作；2026-09-22 后续接入二维挑战（分关草稿与编辑方式、共用通关记录、无答案示例），并按用户授权接入三维挑战与自由创作（体素入口、Z 坐标、七种显式积木示例及作品库）。未新增关卡。不引入课程、账号、C++ 或 Python 反向转换积木。

## 界面与积木

左侧工作台增加「Python / 积木」编辑方式，右侧保持参考与作品上下对照。积木中文分类，沿用深色风格；生成 Python 可展开只读查看，避免同时挤入第三个编辑区。

固定一个不可删除的「决定像素颜色（x，y）」入口，系统仍负责遍历坐标。首批提供：x/y、整数常量、加减乘与取余、绝对值、大小及相等比较、并且/或者/非、如果/否则、返回颜色（固定 0～8 或整数表达式）。函数末尾生成 return 0。先不提供循环、普通除法、变量、自定义函数、任意文本代码积木或移动原点积木。

比较表达式只能接条件插槽；颜色下拉明确区分空白/白色。缺少必要输入、多入口、非法嵌套和未连接的有效积木须给出明确提示；不应默默运行不完整逻辑。运行时除零等错误保留真实生成代码行号，并尽量映射回积木。

## 技术接入

采用 Blockly 13.3.0，按需加载编辑器。Python 生成使用项目自己的受限结构编译器，不依赖 Blockly 内置通用生成器，以便存档校验与源码重建不加载编辑器。自定义入口/坐标/颜色/返回积木，数学和逻辑同样使用自定义的固定类型积木，限制为本方案中的运算。先核对安装版本 API，再锁定依赖；不引入另一套执行环境。

BlocksEditor → 经过校验的工作区 → Python 源码及行号映射 → 现有 PythonRunner → Pyodide Worker → colors → PixelCanvas。

执行仍在 Python 内部遍历，一次返回数组；沿用停止、两秒超时、任务编号与过期结果隔离。生成时处理表达式优先级，不能拼出改变数学含义的代码。只读取唯一入口内的有效语句。

## 文本与积木关系

积木草稿和手写 Python 草稿独立，切换编辑方式不会覆盖另一份内容，也不尝试反向解析任意 Python。结果归属应包含编辑方式；切换取消运行并显示该方式自己的历史作品。

「复制为 Python 作品」单向生成独立副本，并保留原积木作品；不会把手写 Python 缓冲区当作生成代码缓存。语言仍为 python，编辑来源单独记录为 blocks/python。

## 保存与兼容

必须保存 Blockly 工作区 JSON，不能只保存生成代码，否则打开后无法继续搭积木。增加独立版本化的积木草稿；作品文件新增明确支持积木的版本/编辑器标识，继续读取已有二维/三维 version=1 Python 文件，导入不自动执行。

原型接入现有作品库的命名、另存副本、草稿保护、缩略图和 PNG。保存积木作品时同时保存结构及生成代码；打开后从结构重新生成代码，避免执行不一致的外部代码字段。预览按实际生成源码匹配，不能沿用别的代码或编辑方式的历史结果。

工作区恢复前校验块类型白名单、字段、结构、尺寸和数量上限；加载失败保留原存档，不能自动清空或覆盖。沿用先落盘后切换；文件限额需计入工作区 JSON。未知版本给出错误，不降级成空白作品。

## 开发顺序

1. 接入 Blockly 与入口/颜色/判断积木，运行最小像素程序。
2. 补齐运算和条件组合，添加只读 Python 对照及错误处理。
3. 接入独立草稿、编辑方式切换、积木作品保存/导入导出和生成 Python 副本。
4. 验证真实拖拽、刷新恢复、数据保护、PNG 和现有功能回归。

## 验收

- 真实拖拽完成彩色十字或小树，生成结果与同逻辑 Python 逐格一致；负数取余、嵌套条件、表达式优先级有行为测试。
- 未完成拼接明确提示，不覆盖上次成功作品；错误展示对应生成代码，无法可靠映射时不伪造积木定位。
- 切换编辑方式、二维/三维、打开作品时旧运行不能污染新作品。
- 保存、刷新、重新打开后可继续拖拽编辑，手写代码和旧作品原样保留；副本、取消切换、配额失败、非法文件得到验证。
- 中文积木在 1440×900、1180×768 下可拖拽与缩放，工具箱及 Python 对照不遮挡运行按钮。
- lint、build、相关 Edge Playwright 测试通过；改动覆盖执行入口与存档，最终运行全量回归并准确记录结果。
