## 三维剖切

- 中心轴 X/Y/Z 圆形手柄可拖动，每次按整数层调整上界，保留坐标 ≤ 上界的体素；三轴可组合。手柄支持方向键、Home/End。
- 隐藏体素保留淡色点状提示，重新计算截面外露面；不修改原始 colors、代码、运行结果或存档。显示数量另列在剖切状态中。
- “恢复完整模型”恢复全部三轴，“重置视角”只恢复相机。关闭坐标辅助隐藏手柄但保留剖切，并可恢复完整模型。
- 剖切、相机和坐标辅助状态由 App 的 useVoxelControls 共享，在本次页面会话中跨模式切换保留，刷新后重置，不持久化。端视投影过短的手柄不显示，旋转后可操作。

## 必须保留的行为（二维挑战）

- 三关全部开放，按最终像素图判断，不限制解法；完全一致才通关，通关后不自动跳关，后续失败不撤销历史通关。
- 匹配率只统计“目标或结果至少一方不为空”的格子；双方都空不计，集合为空为 100%。非完全匹配最多显示 99.9%。颜色 0 是空白，不是白色。
- 系统逐格调用 `pixel(x, y)`，返回值必须严格为 0～8 的 Python int，排除 bool、float、None。每关首次模板仅含 `def pixel(x, y):` 和 `return 0`，不能覆盖已有代码。
- 默认原点居中，x 向右、y 向上，整数代表格子中心；关卡尺寸固定。目标规则和颜色配置以 `src/engine/levels.ts` 为准，不向学生展示目标公式或错误格定位。
- 左侧代码，右侧上方目标、下方作品；沿用科幻终端风格。画布使用整个矩形视口等比例缩放，格子保持正方形，缩放和平移两图联动。
- 目标图右上角保留“坐标系”和“重置视图”。边缘轴位于矩阵左侧/下方；标准轴在当前原点相交，原点只显示一个 0，x/y 标识位于矩阵外侧正方向箭头旁。X 红、Y 绿。
- 悬停提示位于光标右上方，显示坐标、真实色块和颜色名称；移出格子隐藏。匹配率和历史结果位于作品右上角浮层，不挤占画布。不恢复已删除的画布引导文字。

## move_origin(dx, dy)

在 `pixel()` 外、逐格计算前调用，参数为严格整数；正数向右/向上，多次调用相对累加。每次运行从默认原点重新开始。例如先调用 `move_origin(2, 3)`，再调用 `move_origin(-1, 0)`，最终原点位于初始坐标 `(1, 3)`。

- 执行层调用 `pixel(x - ox, y - oy)`；目标像素位置、数组顺序和实际格子匹配规则不变。允许原点移出矩阵。
- 成功运行后，两图的刻度、标准轴位置和悬停坐标同步更新；边缘轴仍留在矩阵边缘。超出视口的轴裁切。
- 编辑、失败或停止时保留历史作品及其原点；每关会话内保存各自作品与原点，无作品时使用默认原点。重置视图只重置缩放和平移。
- 逐格执行期间调用会报 RuntimeError，参数类型或累计偏移超出实现支持的整数范围会报错，并沿用用户代码行号定位。

## 实现入口与注意点

数据流：App → PythonRunner → Worker → Pyodide / execute.py → `colors[]`、`origin` → App 判定并同步两图。

| 文件 | 职责 |
| --- | --- |
| `src/App.tsx`、`src/App.css` | 界面、运行状态、每关历史作品及原点 |
| `src/runners/` | Worker 生命周期、Python 执行、move_origin、结果协议 |
| `src/engine/levels.ts`、`evaluate.ts` | 关卡配置、目标生成、匹配判定 |
| `src/engine/view.ts`、`src/renderers/PixelCanvas.tsx` | 联动视图、坐标命中、轴和像素绘制 |
| `src/engine/voxel.ts`、`src/renderers/VoxelCanvas.tsx`、`src/hooks/useVoxelControls.ts` | 三维示例/参考数据、渲染、悬停、双图视角与剖切共享状态 |
| `src/hooks/useProgress.ts` | 本地存档、校验和保存异常 |
| `src/components/CodeEditor.tsx`、`HelpDialog.tsx` | 编辑器、错误标记、使用说明 |
| `tests/game.spec.ts`、`playwright.config.ts` | 二维测试及 Edge 测试配置 |
| `tests/voxel.spec.ts`、`voxel-cut.spec.ts`、`voxel-hover.spec.ts` | 三维执行、剖切、悬停测试 |

- 数组按原始 y 从 +radius 到 -radius、每行 x 从 -radius 到 +radius 排列，目标、执行、渲染必须一致。Python 内部遍历，不由 JS 逐格调用。
- 执行限时 2 秒、初始化限时 60 秒；停止/超时重建 Worker，切关取消运行，保留任务编号与 generation 防止旧结果污染。错误行号取自 student.py，不能伪造。Worker 不是完整恶意代码沙箱。
- 存档键 `pixel-code-lab.progress`，schemaVersion=1；保存代码、历史通关、关卡、说明状态及可选 mode / voxelCode / voxelExample / voxelPassed，不持久化作品、原点或视图。刷新后重新运行。损坏存档先保留，不能擅自覆盖；改关卡 ID 或 schema 需考虑迁移。
- 浏览器来源不同会隔离存档，尽量沿用已有地址和端口。Python 与 Monaco 由项目本地提供资源。

## 运行与验证

依赖版本以 package-lock.json 为准；已有依赖无需重装。日常运行 `npm run dev`；检查使用 `npm run lint`、`npm run build`、`npm test`。
