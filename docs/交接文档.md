## 3. 已确认的产品规则

1. 初版只有 Python + 2D 三关挑战，全部开放，无顺序解锁。
2. 不提供自由创作、解题提示、参考答案、错误格定位或叠图对比。
3. 目标图可以放大，悬停查询坐标和颜色；最新提示显示真实色块与颜色名称，颜色编号仍在常驻颜色表中展示。不给学生展示目标公式。
4. 只判断最终像素图是否完全一致，不限制代码写法，硬编码也可以通关。
5. 运行即绘图、计算匹配率和判定；通关后不自动跳关。
6. 坐标关于原点对称，x 向右、y 向上，整数代表格子中心。尺寸按关配置，学生不能修改。
7. 左侧代码，右侧上方目标、下方作品；两图缩放和平移联动，共用重置视图。
8. 每关首次使用统一模板，已有存档不能被示例覆盖：

```python
def pixel(x, y):
    return 0
```

9. 首次执行规则说明 + 常驻颜色表；说明可再次打开。
10. 本地保存每关代码、历史通关记录、上次关卡。刷新后恢复代码与进度，作品重新运行生成。
11. 报错显示原因和可用的用户代码行号。超时等没有对应行号时不能伪造。
12. Windows 电脑为主要环境，默认网络稳定，由学生保证网络可用。手机完整体验不属于首版验收目标。
13. 不引入账号、云存档、社区、AI、排行榜、Blockly、C++、3D、动画系统或关卡编辑器。
14. 最新视觉偏好是科幻终端，不能自行退回白色网站卡片或改成像素街机/明亮积木风格。
15. 坐标系按钮位于目标图画布右上角、重置视图左侧；两张画布同步在“边缘轴”和“原点居中标准轴”之间切换。居中轴的 `0` 只在原点显示一次，`y` 位于矩阵上方、`x` 位于矩阵右侧，均紧邻正方向箭头。

## 4. 关卡和颜色

| ID | 名称 | 范围 | 内部目标规则 |
| --- | --- | --- | --- |
| square | 实心正方形 | x、y 均 -5～5，11×11 | abs(x)≤2 且 abs(y)≤2：红色 1，否则 0 |
| checkerboard | 双色棋盘 | x、y 均 -4～4，9×9 | (x+y) 为偶数：红色 1，否则蓝色 5；原点红色 |
| circle | 实心圆 | x、y 均 -10～10，21×21 | x²+y²≤64：蓝色 5，否则 0，包含边界 |

颜色：0 空、1 红、2 橙、3 黄、4 绿、5 蓝、6 紫、7 白、8 黑。空白不等于白色。最新 Canvas 将 0 渲染为深色底格；`levels.ts` 的 palette[0] 仍是早期浅色占位，Canvas 对 0 做了覆盖，调色模块也单独显示棋盘空白纹理。这不改变判定编号。

## 5. 运行和判定约定

数据流：App → PythonRunner → Worker → Pyodide / execute.py → colors[] → evaluate → Canvas。

- 实际运行结果是颜色编号一维数组，不是原规划示例里的 Pixel 对象数组。
- 数组顺序：y 从 +radius 递减至 -radius，每行 x 从 -radius 递增至 +radius；目标生成、执行和渲染必须保持一致。
- Python 内部遍历坐标；JS 不逐格调用 Python。
- 用户函数返回值必须严格是 Python int 且在 0～8，排除 bool、float、None。
- 匹配率分母为“目标或结果至少一方不为空”的格子数，分子为这些格子中颜色相同的数量。双方都空不计；多画、漏画、错色都扣分。集合为空定义为 100%。
- 完全一致才通关，非完整匹配显示值最高 99.9%，不因四舍五入显示成 100%。
- 后续失败不会撤销历史通关；修改代码或运行失败时，旧作品显示“历史结果”。
- 执行限时 2 秒，初始化限时 60 秒，初始化不计入执行时间。
- 停止/超时 terminate Worker 并重建；切关取消运行；任务编号和 App generation 防止旧结果污染当前关卡。
- 每次创建用户命名空间。stdout/stderr 最多显示 4000 字符；不自动安装额外 Python 包。
- 用户源码以 student.py 编译，从异常栈提取真实行号。非法返回值提示函数定义行并注明含义。
- Web Worker 用于执行隔离，不是恶意代码的完整安全沙箱，不承诺限制所有内存或网络滥用。

## 10. 视觉方向与后续边界

当前：深蓝黑背景，青蓝任务标记，薄荷绿运行与通关反馈，方形技术面板；关卡侧栏 + 代码终端 + 右侧上下双画布。保留高可读代码区，不为游戏感牺牲错误提示或坐标查询。

最新已确认的画布表现：

- 移除画布默认的“悬停查坐标 · 滚轮缩放 · 拖动平移”及页脚同类提示；使用说明弹窗仍保留交互说明。
- 移除目标图右侧 MISSION/复现目标图/坐标范围/原点说明，以及未运行作品的 READY TO CREATE/轮到你了/匹配率 — 引导。
- canvas 填满绘图区，矩阵格子保持正方形。通过实际容器尺寸和 devicePixelRatio 设置绘图缓冲，并用 ResizeObserver 重绘。矩阵可在整个矩形画布中缩放和平移，超出画布边界时裁切。不要恢复固定方形 bitmap 的 CSS 拉伸，也不要恢复 object-fit:contain 导致的中间小方形裁切限制。
- `engine/view.ts` 保留 600 单位的逻辑坐标，`PixelCanvas.tsx` 的 canvasScale/canvasPoint 将其映射至实际视口，绘制与命中使用同一比例，并按坐标系模式为轴标签预留空间。当前缩放范围仍是 1～8 倍。
- 目标图右上角有“坐标系”和“重置视图”按钮；前者在两图中同步切换轴显示，后者重置两图缩放和平移。按钮位置保留上、右边缘留白。
- 边缘轴模式：矩阵左侧为绿色 Y 轴，下方为红色 X 轴，包含箭头、短刻度线和整数标签。标签对齐格子中心：X 从左到右递增，Y 从上到下递减。
- 居中标准轴模式：红色 X 轴与绿色 Y 轴在原点垂直相交；整数刻度沿各轴显示，`0` 只在原点显示一次；`y` 位于矩阵上方、`x` 位于矩阵右侧，均紧邻正方向箭头。此模式会为矩阵外侧轴标识预留空间。两种模式的轴均随矩阵缩放和平移，超出视口时裁切。
- 悬停有效格子时，在光标右上方显示小矩形提示框：`坐标:(x: 3, y: 5), 颜色: [色块]蓝`。X 字段红色，Y 字段绿色；颜色使用真实色块与名称，不再显示编号，0 显示棋盘纹理和“空”。移出格子时隐藏；当前定位使用固定偏移及右边缘限位。
- 作品的匹配率、通关/未匹配、耗时、进度条和历史结果说明放在作品绘图区右上角的半透明浮层中。浮层采用绝对定位，不应再作为右侧网格列挤窄画布。未运行时不显示该浮层。

实现注意：当前 CSS 含多处响应式覆盖，修改单列布局时需检查各断点；窄屏样式会隐藏部分结果装饰及耗时。最新全尺寸视觉回归尚未做，不能把早期多尺寸验证当作最新版本的验证。

原始 2D+3D、多语言规划已被访谈收敛为当前版本。不要根据旧规划把 3D、自由创作或 Blockly 重新加入首版。
